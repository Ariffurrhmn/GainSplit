- **2026-11-10** DELEGATED: **A3/A4/A5 implementation.** (1) Every step uses one L batch and, for U-arms, one U batch of the same size (32), so all arms keep the same step count while U-arms see unlabeled text each step. (2) Helper heads are linear layers on the shared [CLS] vector (3 sentiment, 5 emotion classes), trained on teacher **hard** labels over L+U, total helper loss = w x (sentiment CE + emotion CE), one w for both. Why hard labels: Part 2 varies label form (soft, weighted, ...) against this reference. (3) A4 follows GAN-BERT (Croce et al. 2020): 100-d noise generator MLP, (k+1)-class discriminator MLP on [CLS], supervised + real/fake losses, generator with feature matching. **Clean variant:** the discriminator step uses detached fakes, the generator step updates only the generator. Why: the reference code lets generator-loss gradients reach the discriminator, which mixes the two objectives; the clean form is the textbook GAN and easier to defend. No replication of labeled examples (GAN-BERT's log-scale trick): the fixed L batch per step already balances L against U. (4) A5 = A4 + the A3 helper losses on real vectors. (5) Training curves (loss terms, mean fake-probability on real vs fake) saved per run to check the GAN trains.
